# Elevate Labs Internship

A collection of data analytics tasks completed during my internship at **Elevate Labs**, covering SQL, Python-based analysis, and Power BI dashboards. Each task explores a different stage of the data analytics workflow — from querying and aggregating data to visualizing trends and building interactive dashboards.

Every folder contains its own detailed README with dataset info, methodology, and insights.

---

## Tasks Overview

### Task 1 — [Data Cleaning and Preprocessing](./Task%201)
Cleaned and preprocessed the **Netflix Titles Dataset** using Colab by dropping duplicate rows, filling missing values, standardise fields
- **Tools:** Google Colab, Python, Pandas
- **Highlights:** Cleaned rows, columns, fields and made dataset ready for next steps.

### Task 2 — [Data Visualization and Storytelling](./Task%202)
Explored the **Adidas Sales Dataset** using Power BI to uncover product and regional performance trends.
- **Tools:** Power BI
- **Highlights:** Most profitable products, top retailers and cities, product share across regions

### Task 3 — [SQL for Data Analysis](./Task%203)
Practiced core to intermediate SQL on a **Movies dataset** — filtering, sorting, aggregation, and joins.
- **Tools:** SQLite
- **Highlights:** Genre-wise counts, average ratings, INNER/LEFT joins on movies and ratings

### Task 4 — [Dashboard Design](./Task%204)
Built an interactive **Power BI dashboard** on the Superstore Sales Dataset with KPIs and regional filters.
- **Tools:** Power BI
- **Highlights:** Sales/profit trends, category and regional performance, interactive filtering

### Task 5 — [Exploratory Data Analysis](./Task%205)
Performed EDA on the **Netflix Titles Dataset** to understand content trends over time.
- **Tools:** Python (Pandas, Matplotlib, Seaborn), Google Colab
- **Highlights:** Movies vs. TV shows, content ratings, top genres, actors, and producing countries

### Task 6 — [Sales Trend Analysis Using Aggregations](./Task%206)
Analyzed an **Online Sales Dataset** using SQL aggregation and window functions.
- **Tools:** SQL (Aggregation, Window Functions, Filtering)
- **Highlights:** Monthly revenue trends, order counts, filtered and ranked sales data

### Task 7 — [Sales Summary](./Task%207)
Used SQL inside Python to summarize a custom sales database and visualize results.
- **Tools:** Python, SQLite, Pandas, Matplotlib
- **Highlights:** Total quantity/revenue, top-performing products, revenue distribution chart
